# Bo-Young Choi — academic website

Quarto website with Home, Research, Teaching, and CV pages.

## Preview
Install Quarto 1.10.19, then run `quarto preview`.
Run `quarto render` to produce `_site/`.

## GitHub Pages
Create a public repository and push these files to its `main` branch.
In Settings → Pages, select **GitHub Actions** as the publishing source.
The included workflow builds and publishes the website on each push.
